# Sprinter roadmap

Personal-first MVP target: **November 18, 2026**. These are tentative checkpoints, not hard deadlines. If necessary, extend the personal MVP to **December 2, 2026**.

| Date | Checkpoint | Acceptance criteria |
| --- | --- | --- |
| Nov 5 | Project setup and architecture | Android project builds on the target Samsung phone; data models and navigation defined |
| Nov 7 | Exercise library and routines | Create and reopen a routine with ordered exercises |
| Nov 9 | Active workout logging | Record sets, reps and weight offline; finish and save a session |
| Nov 11 | History and reliability | Review/edit history; recover an interrupted session |
| Nov 13 | Strength insights and export | Display simple records and export workout data |
| Nov 16 | Real-world gym test | Complete a normal workout without Strong; record friction and bugs |
| Nov 18 | MVP review | Decide whether daily use is reliable or extend to Dec 2 |

## Later phases (not in the two-week MVP)
1. Import historical Strong data where the available export format permits.
2. AI-ready read-only data API with authentication and a compatible MCP interface; verify ChatGPT custom connector availability.
3. Confirmed write operations for routines and workout changes; no silent AI mutations.
4. Backup/restore, optional sync and Health Connect integration.
5. Multi-user readiness, privacy policy, testing, Play Console compliance and staged Google Play release.

## Scope control
Avoid cloud infrastructure, subscriptions, social features and AI chat UI until the personal workout logging experience is dependable.
